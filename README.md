# PoE 日本語 → 英語 アイテム変換器

`index.html`をブラウザで開いて使用する静的な公開版。

- 貼り付け
- 英語へ変換
- 変換結果をコピー
- 未変換レポートをコピーしてGoogleフォームから報告
- リセット

PoB必須項目に未変換がある場合は赤文字で表示し、変換結果はそのままコピーできる。報告ボタンは取引メモを除外したレポートをコピーし、Googleフォームを開く。自動送信はしない。

## 注意

非公式ツールです。Grinding Gear GamesおよびPath of Building Communityとは関係ありません。変換結果は保証されません。

Path of Exile and associated data are property of Grinding Gear Games. Item data is derived in part from RePoE.
